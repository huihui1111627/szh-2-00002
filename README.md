# 高层建筑地震主动减振动态推演

这是一个无构建依赖的单页交互原型，用于把楼层位移、加速度、阻尼装置状态、电力余量、余震预测和主动控制策略放进同一个确定性动态模型。

## 运行

在当前目录启动任意静态服务器，例如：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。也可以直接用浏览器打开 `index.html`，导入/导出和自动恢复依赖浏览器 `localStorage` 与 File API。

## 已实现的能力

- 统一动态模型：10 层集中质量剪切型结构，状态包含相对位移、速度、绝对加速度、层间剪力、地面运动和设备状态。
- 主动/被动控制：层间阻尼执行器与连接 5–10 层的主动 tendon；主动力受电力容量、设备健康度和热退化约束。
- 可切换目标：均衡、压顶摆动、层间保护、舒适优先和被动基线。
- 双模型实时对照：当前策略始终与相同地震输入、相同故障顺序下的被动基线并行推演。
- 代价显式呈现：压顶和舒适策略会降低顶部位移/加速度，但可能显著增加 3–6 层峰值剪力。
- 事件组合：主震、余震和设备故障可调整顺序后重建时间线。
- 设备操作：可隔离故障装置；过早隔离健康装置或突破最低冗余会被事务拒绝并回滚。
- 供电切换：市电受地震强度降额影响，电池会被主动力消耗并在市电低负载时充电；低储量切换会触发保护。
- 余震预测：显示预计到达、持续时间和置信度；可决定是否让预测参与供电调度。
- 关键节点：事件开始自动生成分支，也可手动分支，可进入分支做 what-if 推演。
- 回滚：控制目标、隔离/恢复、供电切换等用户操作在执行前保存快照，失败自动回滚，也可手动撤销最近一次操作。
- 确定性复现：固定种子和固定 `0.005s` 物理步长；刷新后从本地状态恢复，也可导出/导入 JSON。

## 操作说明

- `播放` 连续推演，`单步 +0.04s` 每次推进 8 个物理子步。
- 在 `事件编排` 中调整顺序，然后点击 `按顺序重建`。
- 选择楼层后可隔离或恢复对应阻尼装置。
- 点击 `在当前节点分支` 可保存一个可返回的方案节点。
- 点击 `回滚当前操作` 会撤销最近一次成功的用户操作并恢复操作前物理状态。
- `导出推演` 保存完整 JSON；在另一台浏览器中导入即可恢复当前状态。

## 模型边界

该原型用于交互验证、控制策略权衡和流程推演，不代表具体建筑的工程设计。参数采用无量纲/归一化的教学尺度，实际工程需要使用经结构专业校准的质量、刚度、阻尼矩阵、执行器模型、传感器延迟、作动器饱和规范和场地地震动。

## 本地校验

```bash
node --check app.js
```

核心物理函数通过 CommonJS 导出，可用 Node 直接验证固定种子下的可复现性和不同控制策略的指标差异。
