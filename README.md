# 高层建筑地震主动减振 · 确定性推演台

把楼层位移、加速度、阻尼装置状态、电力余量与余震预测放进统一动态模型，可逐步推演
主震 / 余震 / 设备故障 / 断电的任意组合，支持关键节点分支、失败回滚与重启后的确定性复现。

纯前端、零依赖、零构建：直接用浏览器打开 `index.html` 即可（或 `npx serve .` 后访问）。

## 文件
- `sim.js` —— 确定性物理内核（无 DOM，可在 Node 中直接 `require` 测试）
- `app.js` —— 交互、Canvas 可视化与推演编排
- `index.html` —— 三栏界面布局

## 动态模型
- 12 层集中质量剪切模型，半隐式 Euler 积分，步长 `dt=0.01s`，一阶自振周期约 0.98s。
- 6 台主动质量阻尼器（AMD），布置于 2/4/6/8/10/12 层；可在线、故障、人工隔离，含单台出力饱和。
- 控制律为**模态 LQR**：对前 6 阶振型解耦、按当前在线装置集合在线求解离散代数 Riccati 方程；
  故障 / 隔离后增益自动重算。四个控制目标改变模态权重矩阵：
  - 顶层位移最小：强压一阶摆振（顶层位移最低，但顶部层间变形、中下部加速度可能上升）
  - 舒适度（加速度）：优先压低楼层加速度
  - 全楼层间位移角：均匀分配变形，避免薄弱层集中
  - 节能：提高出力代价，峰值期控制余量最小
- 电力：市电 / 自动切换 / 仅备用三模式；备用电池约可支撑 60s 停电。
  仅市电时断电即失电终止；自动模式下电池耗尽终止。
- 地震动：种子化 Clough–Penzien 滤波 + 三段包络合成；主震罕遇、余震多次叠加。
- 余震预测：给出序列内待发生地震的峰值与不确定带，以及 Omori 衰减的 30s 背景超阈值概率。

## 代价显式化（关键需求）
右侧“代价提示”和楼层热区始终用**无控基线**（忽略供电事件、关闭全部装置的全程包络）对照：
- 逐层列出层间位移角超过无控的楼层（红）；
- 列出楼层加速度/受力超过无控 ≥20% 的楼层（黄）；
- 标记最薄弱层是否随策略发生转移；
- “试分支”可在关键节点后离线用另一策略推演，并排比较顶摆与最大位移角。
典型现象：顶层优先策略把顶部绝对位移压到约 14%，但顶部层间位移角可升至 1.3–2.5 倍；
级联故障 / 隔离后，中下部楼层加速度可达无控的 2–6 倍。

## 推演编排
- 播放 / 暂停 / 单步（单步跳到下一事件）/ 拖动时间轴（确定性快进）/ 0.25×–4× 速度。
- ⚑ 关键节点保存完整状态快照（含当时的目标、隔离、供电配置）；可回滚到任意节点改策略重跑。
- 失败（结构位移角超限、失电、电池耗尽）自动终止并提示，可一键回滚。
- 事件可自由增删、排序：主震、余震、指定装置故障、市电中断/恢复；三个预设组合。

## 确定性复现
- 全部随机量来自 `mulberry32(seed)`，地震动按 `(seed, 事件类型, 序号, 时刻)` 派生独立流。
- “复现码”（G 开头的 base64url）编码种子、完整事件序列与配置；导入即可逐位重建。
- “存入浏览器”把复现码与关键节点写入 `localStorage`，重启页面自动恢复。
- 快照恢复后继续推演与从零重放结果完全一致（已用 Node 与无头浏览器校验，最大偏差 0）。
